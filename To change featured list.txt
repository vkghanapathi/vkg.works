How to change the featured?
Edit the .md sidecar file for any article. Add featured: true to feature it, remove that line to unfeature it.

To feature an article — open its .md file and add the line:


---
title: "Kumbhabhishekam Explanation"
date: 2026-02-27
author: "Dr. Vamshi Krishna Ghanapāṭhī"
category: analytical
featured: true        ← add this
---
To unfeature — remove or delete the featured: true line.
